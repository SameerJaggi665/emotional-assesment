## Emotion Assessment ML Model

This project predicts human emotions from text using:
- TF-IDF Vectorization
- Logistic Regression

### Tech Stack
- Python
- Scikit-learn
- Streamlit

### Demo
🔗 Live App: <your-streamlit-link>

### How it works
1. User enters text
2. Text is vectorized using TF-IDF
3. Logistic Regression predicts emotion

### Sample Predictions
"I feel amazing today!" → Joy

"I'm so tired of everything" → Sadness
